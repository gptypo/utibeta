# Útiterv Studio — BETA 1.1.4

## Haladás és kvíz polish

- A „Körbejártad a helyzetet” összegzés teljes kék felületet kapott, fehér szöveggel.
- A főoldalra visszakerült egy kompakt Haladás dashboard.
- A dashboard összesíti a három tanulási modul kvízeit: megválaszolt, helyes és hátralévő kérdések, valamint modulonkénti előrehaladás.
- A modul soraira kattintva közvetlenül megnyitható az adott modul.
- A korábbi szabály megmaradt: ha egy kérdés minden válaszlehetőségét körbejártad, a kérdés helyesként számít az összesítésben.
