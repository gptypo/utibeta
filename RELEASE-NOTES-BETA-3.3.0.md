# Beta 3.3.0 – Accordion design system

- Egységes, 2 px vastag CSS-chevron minden lenyíló komponensben.
- A nyitott fejléc sötétebb fókuszállapotot kapott.
- Animált türkiz fókuszvonal jelzi az aktív elemet.
- Finom nyitási animáció és egységes spacing.
- Egységes hover- és focus-visible állapotok.
- Egy accordion-csoportban egyszerre csak egy elem marad nyitva.
- A csökkentett animációs rendszerbeállítás támogatott.
