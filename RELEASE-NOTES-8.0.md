# Útiterv Studio 8.0 – Installable Edition

## Újdonságok
- Teljes, installálható PWA manifest 192 és 512 px-es ikonokkal
- Standalone mobil UI és safe-area támogatás
- Android natív telepítési banner, iOS telepítési útmutató
- Offline fallback oldal és verziózott cache-stratégia
- Service Worker frissítésértesítés és egykattintásos aktiválás
- Utolsó útvonal és görgetési pozíció visszaállítása
- Első indítási onboarding
- Studio PWA Ready diagnosztikai panel
- Lighthouse/PWA alapoptimalizálások

## Futtatás
A Service Worker miatt HTTP(S) környezet szükséges: `npm run serve`, majd `http://localhost:4173`.
