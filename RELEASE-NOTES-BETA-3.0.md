# Útiterv Studio Beta 3.0 – Inspector & Auto Layout

## Újdonságok

- A tulajdonságmezők a kijelölt elem böngésző által számolt CSS-értékeit mutatják.
- A Studio csak a ténylegesen módosított mezőket menti, ezért a computed értékek nem írják felül automatikusan az eredeti CSS-t.
- Aktuális szélesség, magasság, max-width, min-height, padding, margin, gap, flex/grid, színek, gradient, árnyék és tipográfia.
- Padding és margin oldalankénti szerkesztése.
- DOM breadcrumb a szülőelemek gyors kijelöléséhez.
- Auto Layout presetek: függőleges, vízszintes és grid.
- Az aktuális, nem előre definiált select értékek is megjelennek.
- Reszponzív eszköznézetenként a ténylegesen renderelt értékek olvashatók.
