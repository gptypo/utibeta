# Útiterv Studio 8.3.6 – Mobile Offline PWA Fix

- Mobil Safari és régebbi Android WebView kompatibilitási javítások.
- Az offline PWA indulás cache-first alkalmazáshéjat használ.
- A `?source=pwa` kezdő URL offline is biztosan az indexet kapja.
- A service worker telepítését egyetlen opcionális fájl hibája sem szakítja meg.
- Biztonságos dialog fallback került be a `showModal()` nélküli böngészőkhöz.
- Régebbi böngészőkön problémás API-k kompatibilis megoldásra cserélve.
