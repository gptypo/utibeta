# Pages CMS – Útiterv

Ez a build Pages CMS használatra elő van készítve. A `.pages.yml` a repository gyökerében található.

1. Töltsd fel a mappa teljes tartalmát a GitHub repository gyökerébe.
2. Nyisd meg a Pages CMS-t, jelentkezz be GitHubbal, és válaszd ki ezt a repositoryt.
3. A bal oldali menüben a Főoldal / Önmagam / Helyzeteim / Kapcsolataim / Galaxy Guide tartalmai külön szerkeszthetők.
4. Mentéskor a Pages CMS közvetlenül commitolja a módosított JSON fájlokat GitHubra.
5. Ha a hosztod GitHubról deployol, a következő deploy már az új tartalmat tartalmazza.

A technikai kulcsok el vannak rejtve, az aloldalak szerkezeti listája pedig egyelőre csak olvasható.
