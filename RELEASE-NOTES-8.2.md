# Útiterv Studio 8.2 — Unified Colour System

- Four core palette tokens: turquoise, blue, black and grey.
- Semantic surface, text, border, inactive and accent roles for light and dark themes.
- Existing components now consume the shared token layer through compatibility aliases.
- Turquoise and blue brand surfaces stay unchanged in both themes.
- Black cards remain black and receive turquoise outlines in dark mode.
- Cards, dropdowns and editor surfaces use one theme-aware neutral surface.
- Dark mode text contrast is centralized instead of patched component by component.
- Galaxy Guide and inactive states share the same grey role.
- The existing `#14e8c9` calm/progress accent remains unchanged for compatibility.
