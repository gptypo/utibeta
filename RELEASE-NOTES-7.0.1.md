# BETA 7.0.1 – Optional custom CSS hotfix

- A Pages CMS `customClass` mezői most valóban opcionálisak.
- Üres érték érvényes.
- Ha érték van megadva, továbbra is csak `a-z`, `0-9` és `-` használható, kisbetűvel kezdve.
- A runtime és a tartalomvalidátor változatlanul biztonságosan figyelmen kívül hagyja az üres custom class értéket.
