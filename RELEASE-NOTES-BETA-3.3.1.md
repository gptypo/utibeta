# Beta 3.3.1 – Segédlet utáni témanavigáció

- A témaváltó navigáció mindig a teljes aloldali tartalom legvégére kerül.
- Kvízes témáknál a magyarázat, összegzés és segédlet a témanavigáció előtt marad.
- A gombok már az előző és következő téma nevét mutatják.
- A kártyák saját Előző / Következő lapozója változatlan.
- A témanavigáció vizuálisan továbbra is különálló lezáró blokk.
