# Beta 3.1.2 – Interaction fix

- A Studio inspector többé nem hív `preventDefault`, `stopPropagation` vagy `stopImmediatePropagation` metódust az előnézeti kattintásoknál.
- A flip-kártyák, quiz-válaszok, accordionok, carousel-gombok, linkek és minden más interaktív elem működik Studio módban is.
- Az elemkijelölés passzív marad, ezért a szerkesztő továbbra is követi a kattintott elemet.
- Frissített service worker cache.
