Netlify példa backend beépítve.

A backend ebben a csomagban benne van. A Netlify-on csak az GEMINI_API_KEY környezeti változót kell megadni.

Technikai beállítások

Minimum beállítás: Netlify → Project configuration → Environment variables → GEMINI_API_KEY.
Opcionálisan OPENAI_MODEL. Alapértelmezés: gemini-2.5-flash, a költségtakarékos működéshez. Automatikus production feltöltéshez még NETLIFY_AUTH_TOKEN és NETLIFY_SITE_ID kell; ezek nélkül a jóváhagyott új ZIP egyszerűen letölthető.
