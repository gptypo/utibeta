# Útiterv Studio Beta 3.1.1

## Javítás

- A flip-kártyák ismét működnek az alkalmazásban és a Studio előnézetében.
- Studio módban a flip-kártyára kattintás egyszerre kijelöli a kártyát és átengedi a kattintást az alkalmazás saját fordítási eseményének.
- A többi elemnél az inspector továbbra is megakadályozza a véletlen navigációt vagy műveletet.
- Frissült a service worker cache-verziója.
